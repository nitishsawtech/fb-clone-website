# Facebook Clone Website

## 📌 About the Project

This project is a **Facebook website clone** that I created while learning Git and GitHub during our Git tutorial. The main purpose of this project was to practice my web development skills and understand how Git works for managing and tracking changes in a project.

The project is inspired by Facebook's user interface and design. It helped me gain practical experience in creating a website and managing project files using Git commands.

## 🎯 Project Objectives

* To understand the basics of Git and GitHub.
* To learn how to initialize a Git repository.
* To practice adding and committing files.
* To understand how to track changes in a project.
* To learn how to upload and manage a project on GitHub.
* To gain hands-on experience with website development.

## 🛠️ Technologies Used

The technologies used in this project may include:

* **HTML** – To create the structure of the website.
* **CSS** – To style the website and improve its appearance.
* **JavaScript** – To add interactive features, if implemented.
* **Git** – To track changes and manage versions of the project.
* **GitHub** – To host the project repository online.

## 📚 What I Learned

While working on this project, I learned several important concepts related to Git and GitHub, including:

* Creating a local Git repository using `git init`.
* Checking the status of files using `git status`.
* Adding files to the staging area using `git add`.
* Saving changes with meaningful commit messages using `git commit`.
* Connecting a local repository to a remote repository.
* Uploading project files to GitHub using `git push`.
* Understanding the importance of version control in software development.

## 🚀 Purpose of the Project

This project was created for **learning and practice purposes** as part of our Git tutorial. It helped me understand the basic workflow of Git and how developers use GitHub to store, manage, and share their projects.
